영상 편집 (제작)

촬영 뒤에 남는 노가다 — 무음 자르기, 반복 테이크 지우기, 음량 맞추기, 자막 달기 — 를 자동으로 처리합니다. 원고를 같이 넣으면 원고에 없는 말을 전부 걸러내 정확도가 크게 올라갑니다.

시작하기

편집자동화 폴더를 열고 「2_편집하기」를 실행하세요

D:\유튜브 운용 시스템\편집자동화 폴더 내용 보기
복사한 경로를 탐색기 주소창에 붙여넣으면 폴더가 열립니다.
자주 쓰시면 「2_편집하기」를 오른쪽 클릭 → 보내기 → 바탕 화면에 바로 가기 만들기 를 한 번만 해두세요. 그 뒤로는 바탕화면 아이콘을 두 번 누르면 바로 시작됩니다.

쓰는 법 — 세 단계

1

녹음 파일 + 원고

녹음 파일과 같은 이름의 글 파일(.txt)을 같은 폴더에 둡니다. 원고 없이도 되지만, 넣으면 훨씬 정확합니다.

내영상.m4a
내영상.txt
2

2_편집하기 실행

두 번 클릭하면 파일 고르는 창이 뜹니다. 녹음 파일을 아이콘 위로 끌어다 놓아도 됩니다. 30분 녹음 기준 약 1시간 걸립니다.

받아쓰기가 가장 오래 걸립니다
진행률이 5초마다 표시됩니다
3

캡컷에 넣기

「결과」 폴더의 음성 파일을 캡컷에 끌어다 놓고, 자막은 텍스트 > 로컬 자막 가져오기로 불러옵니다.

1_편집된음성_....m4a
3_자막_....srt
원본 녹음 파일은 절대 건드리지 않습니다. 결과는 항상 「결과」 폴더에 새로 만들어집니다.

나오는 것 — 세 개

파일무엇인가
1_편집된음성 반복·무음·숨소리가 잘려나간 음성(영상이면 mp4). 이게 곧 편집 결과물이라 캡컷에 그대로 넣으면 됩니다. 실행할 때마다 이름 뒤에 시각이 붙어 옛것과 섞이지 않습니다.
2_대본 그 음성에 실제로 담긴 말을 글로 적은 것. 원고와 나란히 놓고 제대로 잘렸는지 눈으로 바로 확인합니다.
3_자막 컷에 맞춰 시간이 정렬된 자막(SRT). 의미 단위로 줄이 나뉘어 있습니다.
검토 보고서·프리미어용 파일·받아쓰기 결과 등은 「결과\자세히」 폴더에 들어갑니다. 그중 받아쓰기_....json 은 지우지 마세요 — 다시 돌릴 때 받아쓰기 시간을 통째로 아껴줍니다.

지금 할 수 있는 것

컷 편집

쓸 수 있음

무음 구간, 반복해서 다시 말한 부분, 말더듬, 숨소리를 잘라냅니다. 원고를 넣으면 원고에 없는 말을 기준으로 판정해 오탐이 거의 없습니다.

음성 보정

쓸 수 있음

치찰음 완화, 잡음 줄이기, 저음 정리, 유튜브 표준 음량(−14 LUFS)까지 자동으로 맞춥니다.

자막

쓸 수 있음

컷에 맞춘 SRT를 만듭니다. 글자수가 아니라 의미 단위로 줄을 나눠 브루보다 자연스럽습니다. 자주 틀리는 낱말은 설정에 적어두면 자동 교정됩니다.

원고 대조

쓸 수 있음

녹음 옆에 원고를 두면 잘못 알아들은 말을 원고 표현으로 되돌리고, 같은 줄을 여러 번 말했을 때 마지막 한 번만 정확히 남깁니다.

롱폼 → 쇼츠 분할

아직 안 써봄

긴 영상에서 1분 내외 세로형 조각을 여러 개 뽑는 기능이 들어 있습니다. 아직 실제로 돌려보지 않았습니다.

2~3캠 싱크

아직 안 써봄

여러 대로 찍은 영상의 소리를 맞춰 한 타임라인으로 붙이는 기능입니다. 아직 실제로 돌려보지 않았습니다.

덜 자르거나 더 자르고 싶을 때

config.json.example·config.json은 지금 연결이 끊겨 있어 고쳐도 아무 효과가 없습니다(2026-09-01 확인). 여유값·문턱값을 고치려면 이 화면에서 직접 바꾸지 말고 클로드에게 "이럴 때 어떻게 조정해줘"라고 말씀해 주세요 — 실제로 값을 읽는 파일 (engine\config.py)을 클로드가 안전하게 고쳐 드립니다.
